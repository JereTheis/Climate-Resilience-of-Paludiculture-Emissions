# Climate-Resilience-of-Paludiculture-Emissions

This repository shares the supplementary R code for the the thesis:  'Climate resilience of paludicultures in Germany – How resilient are greenhouse gas emissions, water levels & yield with a changing climate?'

 This R code works with the dataset for paludiculture emissions produced by the MOOruse project. (https://www.hswt.de/forschung/projekt/958-mooruse)
 
 The code is is split into 3 scripts. The first one handles the preprocessing of the dataset needed for further work. The second script includes data exploration and the fitting of regression models for CH4 fluxes and ecosystem respiration (RECO). The last script works with further data from the climate knowledge portal of the World Bank Group (https://climateknowledgeportal.worldbank.org/country/germany/climate-data-projections). In this script climate change predictions are made with fitted regression models. For this soil temperatures and the water table are adjusted.
